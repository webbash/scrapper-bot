# Bazaraki: поиск квартир и Telegram

`fetch` разбирает одну страницу в JSON. Для закрытого Telegram-чата есть ручная проверка `sync` и бот, который обрабатывает кнопки. Объявления и оценки хранятся в SQLite. Расписания, собственного геофильтра и фонового обхода Bazaraki нет.

На VPS проект разворачивается через [Docker Compose](deploy/DOCKER.md): Go устанавливать на сервер не нужно, `sync` запускается вручную.

## Telegram MVP

1. Создайте отдельного бота через [BotFather](https://t.me/BotFather), добавьте его в закрытую группу для вас двоих и сохраните токен локально. Не отправляйте токен в группу и не коммитьте его.
2. Соберите бинарник и задайте переменные окружения. Пример для zsh:

   ```sh
   go build -o bazaraki-html ./cmd/bazaraki-html
   read -rs 'TELEGRAM_BOT_TOKEN?Bot token: '; echo
   export TELEGRAM_BOT_TOKEN
   ./bazaraki-html chat-id
   ```

   Пока `chat-id` ждёт, отправьте в нужной группе `/chatid@ИмяВашегоБота` (с фактическим username). Команда выведет ID в терминал и завершится. Не запускайте её параллельно с `bot`: Telegram допускает один получатель обновлений для этого токена.
3. Укажите полученный ID, абсолютный путь к общей базе и полный URL выдачи с контуром:

   ```sh
   export TELEGRAM_CHAT_ID='-100…'         # заменить на число, которое вернул chat-id
   export HOUSING_DB_PATH="$PWD/housing.sqlite"
   export BAZARAKI_SEARCH_URL='https://www.bazaraki.com/…'  # вставить полную ссылку
   ./bazaraki-html bot
   ```

   `bot` читает обновления Telegram и не обращается к Bazaraki. Команда `/start@ИмяВашегоБота` в группе проверяет ответ. `/favorites@ИмяВашегоБота` и кнопка **«Фавориты»** открывают общий список.
4. В другом терминале с теми же переменными запустите проверку вручную:

   ```sh
   ./bazaraki-html sync
   # Или передать полный URL как аргумент:
   ./bazaraki-html sync "$BAZARAKI_SEARCH_URL"
   ```

Первый успешный `sync` для чата сохраняет текущие ID **без рассылки**. Дальше скрипт берёт только ещё не обработанные ID из текущей страницы выдачи, открывает их карточки и отправляет одну обложку, цену, район, координаты при наличии и кнопки **«Подходит»** / **«Не подходит»**. При явном отказе Telegram принять фото отправляется текстовая карточка. Если точка приблизительная или её точность не указана, в сообщении это отмечено.

Оценка общая для всего настроенного чата; **«Подходит»** добавляет объявление в отдельный список, **«Не подходит»** убирает его из Фаворитов и удаляет исходную карточку из общего чата для обоих участников. [Telegram разрешает удалять сообщения, отправленные менее 48 часов назад](https://core.telegram.org/bots/api#deletemessage). Если удаление уже недоступно, бот пытается заменить текст или подпись на «Не подходит» и снять кнопки; фото в старой карточке при этом может остаться. Отметка в SQLite сохраняется в любом случае. Повторный запуск и изменения даты или цены не возвращают уже отправленный ID. При ошибке с неизвестным результатом отправки автоматического повтора нет, чтобы не создавать дубли. Новая публикация с другим ID считается отдельным объявлением. Пагинация выдачи и проверка комплектации не входят в MVP.

Оба режима должны указывать на один постоянный файл SQLite. Если `HOUSING_DB_PATH` не задан, используется `housing.sqlite` в рабочей папке. Для автоматизированного доступа и пересылки содержимого используйте согласованный доступ к источнику: [условия Bazaraki, §§4 и 12](https://www.bazaraki.com/about/rules/). Крон не настроен.

Шаблон локального конфига — [`.env.example`](.env.example). Если переменные сохранены в собственном `.env`, загрузите его перед запуском в каждом терминале: `set -a; source ./.env; set +a`. Храните полную ссылку для ручного поиска как `BAZARAKI_SEARCH_URL='…'`, в кавычках, чтобы сохранить `polygon`, `&` и остальные фильтры. После этого достаточно `./bazaraki-html sync`. Файл игнорируется Git; ограничьте доступ к нему командой `chmod 600 .env`.

### Проверка одной карточки

Пока `bot` работает, из другого терминала с теми же переменными окружения отправьте один тест из сохранённого HTML:

```sh
./bazaraki-html test-card snapshots/listing.html
```

Выберите снимок карточки, где есть фото и координаты. Команда не загружает выдачу и не делает запросов к Bazaraki за HTML. Карточка отмечена как **«ТЕСТ»**, видна в Фаворитах после нажатия «Подходит» и не меняет стартовую выборку или историю настоящих ID. Повторный запуск с тем же снимком не продублирует её. Чтобы убрать карточку из чата и Фаворитов, нажмите «Не подходит».

## Парсер сохранённых страниц

Нужен Go 1.25 или новее. Сохраните англоязычную выдачу и карточки в браузере как исходник страницы (в Safari: **File → Save As → Page Source**). Личные снимки можно положить в `snapshots/` — эта папка игнорируется Git.

```sh
go run ./cmd/bazaraki-html search snapshots/search.html
go run ./cmd/bazaraki-html listing snapshots/listing.html
go test ./...
```

- `search` возвращает объявления основной выдачи в её порядке, без повторов по ID и без блоков рекомендаций. Доступные поля: ID, URL, заголовок, цена, метка публикации и район.
- `listing` добавляет год постройки, число спален, категорию меблировки, описание, ссылку на обложку и координаты, если они есть в данных **этого** объявления. Техника отдельно не классифицируется. `price_eur_cents` — целое число евроцентов; если цены в EUR нет, поле опускается. `published_label` — исходная метка вроде `Today`, не точное время публикации.
- Нераспознанная страница возвращает ошибку, а не пустую выдачу. Парсер рассчитан на обследованную англоязычную версию сайта и может потребовать обновления при смене формата.

## Разовая загрузка по URL

Используйте `fetch` для страниц, к которым у вас есть разрешение на автоматизированный доступ: [условия Bazaraki, §4](https://www.bazaraki.com/about/rules/). Ссылка может содержать фильтры — параметры запроса сохраняются.

```sh
url='https://www.bazaraki.com/real-estate-to-rent/apartments-flats/lemesos-district-limassol/'
go run ./cmd/bazaraki-html fetch "$url"

# Сохранить уже разобранные данные:
go run ./cmd/bazaraki-html fetch "$url" > search.json
```

Для карточки передайте URL `/adv/…` той же команде: она сама определит, что скачала, и вернёт один объект объявления. Чтобы сохранить именно исходный HTML для отладки, используйте `fetch-html <url>`.

Обе команды принимают только HTTPS-ссылки на выдачу аренды квартир или отдельное объявление на Bazaraki. Ограничения: 15 секунд, 8 МиБ HTML и до трёх перенаправлений в пределах разрешённых адресов. Ответы `403` и `429` возвращаются как ошибки без повторной попытки. Если скачать страницу удалось, но распознать данные не удалось, `fetch` вернёт ошибку вместо HTML или пустого JSON. Тесты загрузки не обращаются к Bazaraki.

## Поиск по нарисованной области

Нарисуйте область и примените фильтры на Bazaraki, затем скопируйте URL выдачи с параметром `polygon`. Передавайте **полный URL в кавычках**: путь с фильтрами года постройки и числа спален и параметры `polygon`, `ordering`, `price_max` отправляются как есть. Не нужно вручную экранировать `?` и `&` или перекодировать контур.

Bazaraki применяет географический фильтр к выдаче. Это отличается от проверки координат конкретного объявления: в протестированной выдаче с `polygon` точек объявлений не было. Для получения точки или проверки положения у границы понадобится HTML карточки.

## Что с координатами

На сохранённых исходниках от 23 ноября 2026 года:

| HTML | Результат |
| --- | --- |
| Выдача квартир в Лимассоле | 60 уникальных объявлений, у всех указан район, координат объявления не найдено |
| Карточка №6853760, Mesa Geitonia | Есть координаты, `is_approximate: false` |
| Карточка №6859753, Zakaki | Есть координаты, `is_approximate: false` |

В карточках точка хранится во встроенных данных HTML: `location.coordinates`. `is_approximate` — отметка Bazaraki, не подтверждение адреса. Если отметки нет, точность неизвестна. Если точки нет, остаётся название района; подстановка центра района или карты не выполняется.

Ссылка с `polygon` сужает выдачу без загрузки карточек. Если нужна точка конкретного объявления, схема остаётся **выдача → карточка → точка**. Эта выборка не показывает, какая доля остальных объявлений содержит пригодную точку. Команда `fetch` не обходит автоматически ссылки из выдачи.

Исходные снимки сайта не добавлены в репозиторий. В `internal/bazaraki/testdata/` лежат синтетические примеры того же формата, включая страницы без точки, приблизительные точки и многострочное описание.
